# Master-tree materials and HUD-master animation

Independent Windows DreamSeeker / DreamDaemon **516.1688** evidence, 2026-11-01,
synthetic fixture on owned port **18429**. No external game assets or source changes.

`stock.json` retains 23 phases / 69 actual Click receipts. Eighteen independent
224×224 MAP goldens are shared across duplicate phases; the neutral control reuses
the byte-identical composition-matrix control. `frames-*.txt` are independent server
inputs. Resource bytes are reused from `local-relay-world/res`, regenerated by
`prepare.py`. Native `mapnative_test::masterMaterialPixelsAndInput` consumes every phase,
checks pixels within one LSB and exact input expectations, retains pending-vs-rendered
ownership, samples the parallax chain before/during/after its ten-second lifetime,
and checks zero resident texture uploads across material/movement updates.

## Observations

- Affine RGBA matrices inherit as **parent × child**, including offsets, before
  clamping. Parent scalar / child matrix and parent matrix / child scalar both
  matter. Selected master material applies again after the plane capture.
- Nested and same-plane master selection, underlays, KEEP_TOGETHER suppression,
  KEEP_APART and escaped planes retain their existing behavior.
- RESET_COLOR restores inherited RGB output rows, preserving the alpha row;
  RESET_ALPHA restores the inherited alpha output row, including its offset.
- Default child blends inherit ADD/SUBTRACT/MULTIPLY. MULTIPLY owned leaves do not
  contribute mouse ink; the world member under the master still receives clicks.
- `parallax` combines a white-mask master with an overlay and a second, opaque-alpha
  multiply master running VG's no-op ten-second color animation. Both pieces must
  remain present; a missing mask or temporarily omitted multiplier changes pixels.

## Capture provenance and limitations

Local raw evidence: `build/master-material-probe/stock-guarded/result.json` and
adjacent captures/wire. Each collector result fingerprints executables and staged
sources/DMB. Stock owner `20261101T215626Z-3596a43d`, server owner
`20261101T215624Z-5a0a9a18`. Stock uses `-new -guest` with existing global UI settings;
Fugue uses fresh isolated guest state. Registry/global settings were not cleared.

Both clients restore/resize once at physical (80,80), then execute the same fresh
reset and ordered phase history, without Fit/zoom. DPI 144; stock client 448×473
physical, Fugue 672×710. Three visible controls calibrate the 224×224 source MAP
(stock 2×, Fugue 3×); this is source-raster parity, **not equal-window UI/DPI parity**.
Each phase waits for a fresh READY receipt and 800 ms settling; capture and input
validate owned foreground, geometry and cursor. Source pixels are zero-based,
top-left; callback icon/screen units are BYOND one-based, bottom-origin.

An initial diagonal-matrix experiment was transmitted by BYOND as scalar color.
Those raw runs remain local and are not the retained matrix evidence. The next
true-matrix run (`stock-final`) aborted after a pointer-coordinate mismatch in
phase seven; its partial output is not counted. The fresh guarded restart completed
all 23 phases. Initial implementation `default/result.json` matched all pixels
within one LSB (1,024 one-LSB differences, none larger) but missed the MULTIPLY
owned-leaf click; that failure is preserved, not counted as an input pass.

The source is a reproduction oracle, not a claim of arbitrary affine/filter/group
animation, general HUD-root animation, or whole-game parallax parity. Material
animation admits scalar RGBA and **unchanged matrices** on stable unfiltered/
untransformed HUD masters. Changing matrices (including scalar/matrix transitions),
unsupported chain flags/easing, structure changes, malformed matrices and work
limits remain refusals. General master-tree depth/placement/surface budgets remain unchanged.

## Reproduce

Stage with `python -B tests/data/master-material-world/prepare.py build/<new>` and
compile `world.dme` with stock `dm.exe`. Launch a separate safe/invisible server
on an unused port and connect one client at a time. Select the explicit cases in `stock.json` through the staged
`phase.txt`; wait for READY and stable foreground/geometry. Capture native stock
MAP pixels and Click receipts at source points `(40,168)`, `(60,168)` and `(104,104)`.
The shared control golden is retained locally as `stock-control.png`.

The broad matrix capture driver is no longer retained. Fresh collection is manual;
record DPI, calibration and resize/reset history, and never regenerate stock
expectations from Fugue. Stop only recorded owned processes. Full windows, partial
runs and raw logs stay under `build/`, not Git.
